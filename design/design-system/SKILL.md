# Design System — `pixz.design.design-system`

## Methodology
1. Tokens: color, type, space, radius, motion — semantic naming.
2. Components: 1 canonical per pattern; props API minimal; states covered.
3. Governance: contribution + deprecation + versioning; anti-slop check for template duplication.
4. Verify: a11y + visual regression + consistency scan (no duplicate components).
